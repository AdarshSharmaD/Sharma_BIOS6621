# Sharma_BIOS6621

Repository for BIOS_6621 Statistical Consulting.
Author: Adarsh Sharma

## Project folders

- Background: Study descriptions, assignment instructions, data dictionaries, and reference materials.
- Code: R scripts for data preparation and statistical analysis.
- Reports: R Markdown reports and their knitted HTML, Word, or PDF output.
- DataProcessed: Cleaned or transformed datasets created by code.
- DataRaw: Original datasets.

## Reproducibility

Data corrections will be made in code rather than by editing the raw data.
Reports will use relative file paths so the project can run on another computer.
